# Panda Counter – Punktezähler

Persönlicher Punkterechner für ein Würfelspiel mit Pandas. Eine einzige `index.html`,
kein Build, kein Backend – läuft offline, jede Person auf ihrem eigenen Handy, ohne
Sync zwischen Geräten.

Optik: Bahnhofs-Klapptafel (Split-Flap) – siehe `DESIGN.md`. Produktrahmen in
`PRODUCT.md`.

Live: https://lars-sunson.github.io/panda-counter/

## Schriften

Oswald, Space Mono und DM Sans sind in `index.html` eingebettet (Latein-Teilmenge) und stehen unter der
**SIL Open Font License 1.1** (https://openfontlicense.org). Urheber laut Google Fonts: Oswald – Vernon Adams,
Kalapi Gajjar, Cyreal; Space Mono – Colophon Foundry; DM Sans – Colophon Foundry, Indian Type Foundry,
Jonny Pinhorn. Es wird nichts von Google nachgeladen.

## Hinweis

Inoffizielles Fan-Hilfsmittel, nicht vom Verlag und nicht mit ihm verbunden. Alle Namen und Spielinhalte gehören
ihren Inhabern.
